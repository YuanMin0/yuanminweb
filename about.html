部署到 GitHub + Cloudflare Pages

三步上线，零成本
  1. 把 medilearn 目录推到 GitHub 仓库（分支 main）。
  2. 登录 Cloudflare Dashboard → Workers & Pages → Create → Pages → Connect to Git，选择该仓库。
  3. 构建设置留空（Build command 不填、Build output directory 填 / 或 .），点击 Save and Deploy。
ℹ 本地预览
站点无构建步骤，直接双击 index.html 即可打开。若浏览器对本地文件有限制， 在该目录执行 python -m http.server 8080，再访问 http://localhost:8080。

学习进度保存在哪里？

全部保存在浏览器的 localStorage 中，不会上传到任何服务器。清除浏览器数据会同时清空进度与错题本。
