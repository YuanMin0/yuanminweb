第四章 临床诊疗伦理

学习目标：掌握临床诊疗的四大伦理原则；掌握临床诊断、临床治疗、特殊科室诊疗的伦理要求。

一、临床诊疗的伦理背景

  • ①诊疗技术的双重性
  • ②服务对象的特殊性
  • ③疾病过程的复杂性
  • ④医务人员的差异性

吴孟超："我们要治的不是人的病，而是病的人。"

二、临床诊疗的伦理原则

（一）生命至上

  • 是临床诊疗的出发点/落脚点，是医德教育/医德评价的依据，是培养医德情感、锻炼医德意志、坚守医德高地的动力。
  • 《黄帝内经》："天覆地载，万物悉备，莫贵于人。"
  • 《千金方》："人命至重，有贵千金，一方济之，德逾于此。"
  • 二十大报告：坚持人民至上、生命至上……最大限度保护了人民生命安全和身体健康。

（二）最优化原则

  • 实际是一项技术原则：技术手段的正确选择、运用，对就医者的高度负责、真诚关爱。
  • 要求：痛苦最小、耗费最少、效果最好、安全度最高。
  • 收益（理想预期）与损害（现实情况）的权衡；以医疗技术为基础，以因人而异的病情为依据。
  • 表4-3：不同医疗情境下患方选择倾向（治疗效果、治疗花费、身体痛苦、安全性四个维度的权重因情境而异）。

（三）知情同意（informed consent）

  • 定义：医务人员在确定和实施诊疗措施前，应向患者作详尽的解释说明，并取得患者在充分理解基础上自由表示出来的同意。是医学伦理基本原则的临床实践体现。
  • 要件：告知、理解、能力、自由。
  • 形式：口头同意、书面同意。
  • 主体：18岁以上、有自主行为能力者。特殊情况可直接行使医疗特权，无须患者同意。
  • 发展历程：
  • 1947年《纽伦堡法典》：包含十条医学人体试验伦理准则，是医学科研知情同意原则的先声；
  • 1964年《赫尔辛基宣言》：世界医学联合会通过，第一次明确知情同意问题，区分"治疗性研究"和"非治疗性研究"；
  • 1973年美国《病人权利法案》：将其作为重要患者权利以成文形式确立；
  • 2024年10月，第75届世界医学会全体大会（芬兰赫尔辛基）通过《赫尔辛基宣言》最新修订本（第25-29条详述知情同意）。
  • 国内法规：《医院诊所管理暂行条例》（1951）规定施行大手术或特殊治疗须取得患者及关系人同意签字；不能自立之未成年病人或病人已失去知觉且无关系人时可不取得同意，但须共同签字鉴证。

（四）保守医密

  • 保密范围：患者信息、病历资料、经济状况、病史相关信息、性生活信息、家庭信息等；形式涵盖文、图、声。

小结：临床诊疗伦理原则——生命至上、最优化、知情同意、保守医密。诊疗中要兼顾：身体上治疗、心理上关怀、经济上考虑、政策上指导、文化上尊重。

三、临床诊断的伦理要求

（一）问诊

  • 举止端庄，态度热情
  • 全神贯注，耐心倾听
  • 语言得当，正确引导
  • 适度接触，适当辅诊

（看、听、说、触）

（二）体格检查

  • 中医：望诊、闻诊、问诊、切诊；西医：望诊、触诊、叩诊、听诊。
  • 伦理要求：全面系统，认真细致；关心体贴，减少痛苦；尊重患者，心正无私。

（三）辅助检查

（一）医生：

  • 审慎确定检查项目
  • 知情同意，尽职尽责
  • 综合分析检查结果
  • 通俗解释临床诊断（案例：西安医生连续10年手绘术前指导，用画图方式让患者理解专业词汇）

（二）医技人员：

  • 严谨求实，防止差错
  • 尊重患者，工作敏捷
  • 精心管理，保证安全
  • 积极进取，加强协作

（反面案例：日本医院忘接氧气管致患者昏迷——缺少双人核对机制、警报疲劳）

四、临床治疗的伦理要求

治疗分类：药物治疗、手术治疗、营养治疗、心理治疗、康复治疗。

（一）药物治疗的伦理要求

（一）医生：

  • 对症下药，剂量安全：明确诊断和药物性能、适应证和禁忌证，标本兼治；因人而异（年龄、体重、体质、重要脏器功能状况）掌握剂量。
  • 合理配伍，细致观察：掌握配伍禁忌、限制药位数；杜绝滥用联合用药、预警耐药性；了解疗效和副作用，视情调整。
  • 节约费用，公正分配：常用药、国产低价药优先于贵重药、进口药；不开大处方、"人情方"；进口药、贵重药公正分配。

（二）药剂工作人员：

  • 规定必须皮试的药品，处方医师应注明过敏试验及结果；
  • 操作正规，质量达标：不将就凑合、不能掺假；
  • 忠于职守，廉洁奉公：抵制假劣药进库、清查在库药品、执行毒麻药品管理规定、合理分配药品资源。

（反面案例：桐庐县第一人民医院药剂科王晓俊受贿1200余万元，被判有期徒刑14年）

（二）手术治疗的伦理要求

（一）手术前：

  • 准确掌握指征，手术动机纯正：适宜手术——手术是最理想疗法、当前术式是最优解、具备实施条件；不适宜手术——有更优疗法、手术可做可不做、可能加速病情恶化甚至死亡、需手术但条件不具备。
  • 患者或其家属知情同意。
  • 认真做好术前准备：医——方案、技术、设备、药品；患——生理、心理、经济。
  • 新术式/新技术的伦理审查。
  • 术前讨论：主持——非常熟悉患者病情的主治医生；参加——科室或院负责人（重大、危重病例）；内容——①疾病诊断情况 ②手术治疗的必要性 ③手术方式选择依据 ④术中术后可能并发症及意外 ⑤拟采取的预防措施 ⑥手术治疗的预后和经费估计。
  • （案例：CBD感染期间孕妇剖宫产"小平安"）

（二）手术中：

  • 关心患者，体贴入微（适度共情、及时安慰）；
  • 态度严肃，作风严谨（操作稳、准、轻、快）；
  • 精诚团结，密切协作（团结、开放、承担）。

（三）手术后：

  • 严密观察，勤于护理；
  • 减轻痛苦，加速康复。

（三）其他治疗的伦理要求

心理治疗：熟练掌握心理治疗的知识与技巧；感同身受；心态健康、积极、稳定；保守患者秘密与隐私。

饮食营养治疗：营养安全科学；创造良好环境；满足患者的饮食习惯和营养需求。

康复治疗：理解与尊重（平等、真诚相待）；关怀与帮助（鼓励主动、长期治疗）；联系与协作（医务人员、工程技术人员、社会工作者、特种教育工作者）。

五、特殊科室诊疗的伦理要求

（一）急诊科诊疗

时间紧、任务重；患者心理波动大，医患沟通难以充分，需多学科合作。要求：维护患者利益；迅速准确处置；尊重患者权利；如实真诚沟通；尊重患者隐私；医际公正诚实。

（二）妇产科诊疗

兼顾孕妇和胎儿两方面，从单纯疾病诊治和产科处理扩展到围生期、妇女保健和优生优育。要求：尊重妇女的人格；保护患者隐私；弘扬奉献精神；慎重对待女性生殖器官疾病（当下+未来）。

（三）老年病科诊疗

病程长、恢复慢；无明显症状体征、初期不易察觉、合并症多。要求：尊重老者的身心感受；转变理念，合理管理和治疗；有节制、可持续治疗；重视心理关怀。（国家卫健委推10项举措帮助老年人就医；"互联网+护理服务"）

（四）ICU诊疗

  • 冲突：生命维持与生存质量抉择；技术密集与人文支持矛盾；情感决策与理智选择冲突；资源分配与价值公正拉扯。
  • 应对：心理支持、情感沟通；公平收治、资源分配；经济伦理、适度医疗；终末期决策、放弃治疗。

六、知识点总结

  • 诊疗原则：生命至上；最优化原则；知情同意；保守医密
  • 诊断要求：问诊④ / 体格检查③ / 辅助检查④＋④
  • 治疗要求：
  • 药物：医生④ / 药剂人员④
  • 手术：术前（准确掌握指征、动机纯正、知情同意、术前准备、伦理审查）；术中（关心体贴、态度严肃作风严谨、精诚团结密切协作）；术后（严密观察护理、减轻痛苦加速康复）
  • 其他：心理④ / 营养③ / 康复③
  • 特殊诊疗要求：急诊科 / 妇产科 / 老年病科 / ICU

七、课后思考
