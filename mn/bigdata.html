智能、数据与医学大数据基础

智能与人工智能

基本概念名词解释绪论

一、智能的本质

智能 = 知识 + 智力。其中知识是人类智能行为的基础，智力是能够感知、理解、获取、记忆、应用知识的能力。

智能的五大特征：感知能力、记忆能力、思维能力、行为能力、学习能力。

单选题常把「知识 + 能力」和「知识 + 智力」混在一起。正确表述是 知识和智力的总和。

二、图灵与人工智能的提出

三、人工智能的定义

人工智能是关于知识的科学：研究使用计算机模拟人类智能行为（学习、推理、思考、规划等），继而用于研究知识的发现、表征与应用。

四、人机智能的关系

人工智能是人类智能的投影与拓展延伸：通过计算机模型模拟人类智能处理实际问题，并通过反馈持续优化效能。注意方向——是「人工智能对人类智能的模仿与拓展」，而不是反过来。

「智能与人工智能的关联」多选题中，正确项是「人工智能是对人类智能的模仿」「人工智能是对人类智能的拓展」；凡是把人类智能说成「对人工智能的拓展/延伸」的都是错的。

三、大数据与医学大数据

大数据的三大论断：大数据是人们获得新知、创造价值的源泉；大数据是改变市场、组织机构以及政府与公民关系的方法；大数据的核心是预测。2011 年全球生产数据 1.82 ZB。

大数据（国标 GB/T 35295-2017）：具有体量大、来源多样、生成极快且多变等特征，难以用传统数据体系有效处理的海量数据集。

医学大数据：以电子健康档案、电子病历、电子处方为核心，融合可穿戴设备等个人健康数据，构建人口健康信息资源库，用于群体健康监测与疾病诊疗。

大数据国家标准是 GB/T 35295-2017，选择题常直接考这个编号。

四、数据存储单位

换算链：[[bit → Byte → KB → MB → GB → TB → PB → EB → ZB → YB → BB → NB → DB]]，其中 1 Byte = 8 bit，其后各单位均为 1024 倍递进。

影像数据量计算：总 bit 数 ÷ 8 = 总字节数，再 ÷1024 得 KB。例如 20 层 × 512×512 像素 × 12 bit = 7 864 320 B ÷ 1024 = 7680 KB。

医学信息标准

信息标准必考场景对应

一、为什么需要标准

标准需求：解决名词术语与编码不统一、传输格式不规范、系统异构兼容等问题，打破「信息孤岛」。

标准化的三项要求：Consistency 一致性、Interoperability 互操作性、Repeatability 可重复性。

标准定义：卫生业务中信息采集、传输、交换、利用的统一规则、概念、术语、代码和技术。

二、四大常用标准（场景对应表）

标准全称/含义适用场景关键细节
ICD国际疾病分类疾病与健康问题编码转换为字母数字编码；ICD-10 含 21 章、2036 个类目
SNOMED-CT系统化临床医学术语集临床术语标准化与 ICD 同属生物医学术语类
HL7卫生信息交换标准电子健康信息交换含 V2、V3、CDA、FHIR 等子标准
DICOM医学数字成像与通讯标准医学影像的生成、存储、传输影像设备互通的基石
LOINC逻辑观察标识符命名和编码化验检查实验室检验项目编码
电子病历 → ICD / SNOMED-CT；化验检查 → LOINC；影像传输 → DICOM；信息交换 → HL7。这组对应几乎每套卷子都会出现。

三、按功能分类

核心类别包括：生物医学术语（ICD、SNOMED-CT）、分类代码标准（DRG）、信息交换标准（HL7、DICOM）、标识标准、文档和消息规范等。

DRG（疾病诊断相关分组）属于分类代码标准，是医保支付方式改革的核心工具。

数据分析流程与数据预处理

数据处理PCA流程

一、数据分析基本流程（六步）

明确目标 → 数据收集 → 数据预处理 → 分析建模 → 数据可视化 → 报告撰写。

二、为什么要预处理

现实数据是「脏数据」，普遍存在重复、不完整、不准确、不一致、高维度五类问题，直接建模会导致结果失真。

三、关键策略

策略做法说明
数据离散化二值数据（男→1、女→0）；多值数据用数值法或 One-hot 编码把连续量转为类别量
数据规范化最小-最大标准化：映射到指定区间；Z-score 规范化Z-score 对离群点不敏感
数据降维主成分分析 PCA把多变量重组为正交综合变量，保留核心信息
经典例题：把 31 个地区、10 项医疗指标降维至 3 个主成分，累计贡献率 93.05%。这三个数字常出现在填空或选择中。
最小-最大标准化对离群点敏感，Z-score 规范化对离群点不敏感。题目问「哪种方法对离群点不敏感」选 Z-score。

流派三驾马车框架

一、三大流派对比

流派代表人物核心思想研究领域特点
符号主义（逻辑学派）Simon、Newell、麦卡锡认知本质是符号操作，机器通过逻辑规则模拟人类推理专家系统、知识库、机器证明可解释，依赖手工知识
连接主义（仿生学派）Hinton、Yann LeCun智能源于人脑神经元连接，用人工神经网络模拟大脑深度学习、类脑计算、认知科学不可解释，依赖数据
行为主义（控制论学派）Wiener、Brooks智能取决于感知与行动，通过环境反馈与奖惩机制学习自动驾驶、机器人、演化计算可解释，侧重实际应用

机器学习与深度学习

机器学习原理与模型分类

机器学习模型分类易混辨析

一、起源与定义

机器学习由 Arthur Samuel 于 1959 年提出，核心是通过训练数据挖掘规律，用于测试数据预测，再通过评估结果优化模型效能，即「基于过去，预测未来」。代表性早期成果是 Samuel 的跳棋程序。

人工智能 ⊇ 机器学习 ⊇ 深度学习。人工智能是上位概念，机器学习是人工智能的核心实现方法。题目问「机器学习与人工智能的关系」→ 选「后者包含前者」。

二、算法框架全流程

特征选择 = 从原始特征群组中选取特征子集（不改变特征本身）；特征降维 = 把特征映射到新的低维空间（会产生新的综合特征）。两者原理不同，这是经典选择题。

三、模型分类及核心场景

类型数据核心任务医学场景
监督学习带标签数据分类（标记离散）、回归（标记连续）病变良恶判断（分类）、血糖水平预测（回归）
无监督学习无标签数据聚类（按相似性分组）乳腺癌分子分型
半监督学习少量有标签 + 大量无标签提升模型性能标注成本高的影像数据
「半监督学习仅使用无标记数据训练，监督学习仅使用有标记数据训练」——错误。半监督学习是两者结合。另外「聚类、降维属于监督学习任务」也是错的，它们属于无监督学习。

四、模型评估

分类模型评估「分类正误」，回归模型评估「预测值与真实值的差异」。

神经网络与卷积计算

深度学习CNN计算题

一、深度学习与传统机器学习的区别

对比维度深度学习传统机器学习
特征提取自动提取高层次特征，无需人工干预依赖人工设计特征
处理流程端到端连续流程（原始数据→输出）多阶段拆分（特征提取→模型训练→预测）

深度学习由 Geoffrey Hinton 等人于 2006 年提出，是机器学习的子集。

二、神经网络基础

人工神经元接收输入（x₁~xₙ）、权重（w₁~wₙ）和偏置（b），通过加权求和 + 激活函数输出结果。

多层感知器（MLP）：输入层（接收原始数据）→ 隐藏层（逐层提取特征）→ 输出层（输出预测结果）。

代表性模型：CNN（卷积神经网络）、RNN/LSTM（时序数据处理）、GAN（生成对抗网络）、Transformer（注意力机制）。

三、卷积网络关键环节

层作用关键点
卷积层核心特征提取卷积核 Kernel、滑动窗、步长 Stride、填充 Padding；本质是对数据加权（点乘）提取边缘与纹理
池化层降维与特征汇聚最大池化取局部最大值保留显著特征；平均池化取局部平均值平滑特征；不改变特征图深度
全连接层分类/预测位于网络末端，通过 Softmax 转化为概率

四、输出尺寸计算公式（必背）

W2 = (W1 + 2P - Wk) / S + 1
H2 = (H1 + 2P - Wk) / S + 1
输出深度 = 卷积核数量

W1/H1：输入宽/高   Wk：卷积核尺寸   P：Padding   S：Stride
① 输入 10×10，卷积核 3×3，P=1，S=1 → (10+2−3)/1+1 = 10×10（尺寸不变）。
② AlexNet CONV1：输入 227×227×3，96 个 11×11 卷积核，S=4，P=0 → (227+0−11)/4+1 = 55×55，输出深度 96。

五、典型卷积网络

模型特点
LeNet-5早期经典，用于手写数字识别，含卷积层、下采样层、全连接层
AlexNet2012 年 ILSVRC 夺冠，引入 ReLU 与双 GPU 并行
ResNet引入残差块与 BatchNorm，解决深层网络梯度消失，可传递底层信息到高层
ViT用 Transformer 处理图像，大规模数据集下效果优于 CNN
池化层不仅能降维，还能通过局部特征汇聚实现去噪（最大池化保留显著特征、抑制噪声）。说它「无法减少噪声影响」是错的。

感知智能：自然语言处理与计算机视觉

自然语言处理的技术流程

NLP技术流程必考

一、NLP 的定义与两大方向

自然语言处理通过计算机与 AI 技术对人类自然语言进行有意义的分析与处理，核心是 NLU（自然语言理解） 与 NLG（自然语言生成）。

方向含义例子
NLU 自然语言理解使机器理解文本内涵、消解歧义「他的父亲做了手术」中判断父亲是患者而非执行者
NLG 自然语言生成把非语言数据转化为人类语言医学影像报告自动生成

NLP 模仿人类语言学习路径（字→词→语句→篇章→语法规则），通过「模仿—表征—拓展—延伸」实现语言处理。

二、核心技术流程（底层到高层）

环节任务示例
分词把文本拆为最小语义单位「脑实质未见异常强化信号」→ 脑实质 | 未见 | 异常 | 强化 | 信号
词性标注标注词语语法类别名词 n、动词 v、形容词 a；需解决兼类词问题
实体识别识别关键实体脑池、肺癌、EGFR 突变
实体标准化统一多元指代把「无」「未见」「未发现」统一为「无相关异常」
实体关系抽取挖掘实体间语义关联肺癌-转移-骨、症状-对应-疾病
语义分析分析深层语义关系格文法、语义角色标注
常用基于词典的机械分词法：按词典最大长度匹配，不匹配则缩短字符串继续匹配。

三、语义分析的两个工具

「格文法分析的是句子的表层语法结构（主谓宾），而非深层语义关系」——错误，说反了。另外「语义角色标注分析的是其它成分与谓词的关系」是正确表述。

NLP 关键模型与医学应用

模型Transformer医学应用

一、模型演进主线

模型提出时间核心机制局限/优势
RNN1986循环结构处理时序文本存在梯度消失/爆炸，难以捕捉长距离依赖
LSTM1997遗忘门、输入门、输出门解决长距离依赖，NLP 早期核心模型
Transformer2017自注意力机制（Self-Attention）摆脱时序依赖，可同时捕捉全局语义关联，是预训练模型的基础
BERT2018双向预训练（掩码语言模型 + 下一句预测）擅长理解任务：文本分类、实体识别

BERT 双向、擅长理解；GPT 单向、擅长生成。Transformer 的核心是自注意力机制，能同时捕捉所有词语的关联，无需按顺序处理。

三、序列变异与同源性

DNA 复制常见错误：SNP（单核苷酸多态性）、插入（INSERT）、缺失（DELETE）。其中 SNP 指单个核苷酸发生替换。

同源性前提：假设序列源于共同祖先。核心命题是「同源一定相似，相似不一定同源」。

同源类型成因功能
直系同源不同物种中垂直进化（物种形成）而来保留原始功能
旁系同源同一物种中基因复制产生可能进化出新的相关功能
人 α-珠蛋白基因与人 β-珠蛋白基因属于旁系同源（同一物种内基因复制）；人与小鼠的血红蛋白基因属于直系同源（跨物种垂直进化）。

四、Needleman-Wunsch 算法（全局比对）

该算法计算两个序列的最长公共子序列（LCS），量化相似性。

若 ai = bj：LCS(i, j) = LCS(i-1, j-1) + 1
若 ai ≠ bj：LCS(i, j) = Max( LCS(i-1, j-1), LCS(i, j-1), LCS(i-1, j) )

四、诊断效果量化评估（难点 + 计算题）

四格表患病未患病
辅诊阳性TP 真阳性FP 假阳性
辅诊阴性FN 假阴性TN 真阴性
敏感度 TPR = TP / (TP + FN)   —— 患病者中被检出的比例，反映「不漏诊」
特异度 TNR = TN / (TN + FP)   —— 未患病者中被排除的比例，反映「不误诊」
准确率 ACC = (TP + TN) / 总样本数
假阳率 FPR = 1 − 特异度      假阴率 FNR = 1 − 敏感度
300 名患者，阳性 170（TP 160、FP 10），阴性 130（FN 20、TN 110）。
敏感度 = 160/(160+20) ≈ 88.9%；特异度 = 110/(110+10) ≈ 91.7%；准确率 = (160+110)/300 = 90%。

AUC 区间评价
0.9~0.99优秀
0.8~0.89良好
0.7~0.79一般
0.5~0.69较差

二、理论框架与原理

核心框架：输入（Token 化 → 词嵌入）→ 计算（Transformer 架构）→ 输出（自回归生成）。

Q = [2,1]（疼痛），K1 = [1,2]（胆囊炎），K2 = [0,1]（肺炎），d = 2（√d ≈ 1.414）。
原始分数：Q·K1 = 4，Q·K2 = 1；缩放分数：4÷1.414 ≈ 2.8，1÷1.414 ≈ 0.7；模型更关注 K1（胆囊炎）。

三、医学应用

核心场景：病历自动生成（结构化率 98%）、影像诊断、手术方案规划、USMLE 考试（Med-PaLM 2 通过率 85%）、多模态会诊。GPT-4 在复杂问答中接近人类专家，而轻量化微调模型在判别型任务（实体抽取）中占优。

四、具身智能

具身智能是通过主动感知与认知物理世界、做出符合人类预期行为响应的 AI 系统，强调自主交互与学习，属于行为主义学派。核心要素：感知（CNN、ViT）→ 决策（LLM、WMs）→ 行动（机器人控制）。

阶段时间特征
早期萌芽1950s—1990s符号主义主导，「逻辑规则 + 机器人」尝试（如 WABOT-1）
技术积累1990s—2020sBrooks 发表《Intelligence without representation》，提出「感知→行动」框架
技术突破2022 至今大模型赋能，人形机器人爆发（Google PaLM-E、RT2、中国「天工」机器人）
「道」（算法）：CV/NLP/RL → LLMs/MLLMs → 世界模型 WMs。「器」（硬件）：自动化 → 大模型 + 机器人（「20 岁大脑 + 1 岁身体」）→ 自主化。挑战包括仿真到现实的鸿沟、数据稀疏、泛化性、可解释与安全性。

临床应用：智能超声检查（FARUS 机器人自动分析 TI-RADS 分级）、手术室（CARES Copilot 2.0 多模态手术大模型）、自然腔道介入机器人（支气管镜介入）、虚拟小鼠（模拟真实小鼠行为预测神经活动）。

二、可解释性理论（难点）

维度内在可解释 Interpretable事后可解释 Explainable
本质模型本身为白盒黑箱 + 事后解释工具
方法线性回归、决策树、CAMSHAP、LIME、Grad-CAM
适用场景急诊、手术、危急值筛查、辅助诊断
「深度学习 + Grad-CAM」「随机森林 + LIME」「XGBoost + SHAP」都属于事后可解释，只有决策树、Lasso 回归这类本身结构透明的模型才是内在可解释。

SHAP 计算特征的边际贡献加权平均；LIME 做局部线性近似；Grad-CAM 用于图像类 AI 可视化。局限是解释精度与模型性能不可兼得，并存在「解释悖论」（无限追问）。

急诊心梗风险分层需 30 秒出结果且医生能直接理解逻辑 → 选 Lasso 回归（内在可解释、计算快），而不是深度学习集成模型。

三、医学 AI 的伦理问题（四大原则）

具体伦理问题：数据伦理（知情同意伪命题）、算法偏见、责任归属、透明度缺失、医生角色异化。核心立场是：AI 是「医生助手」而非「替代者」，坚守「以患者为中心」。

四、伦理解决策略

问题策略
数据伦理区块链动态知情同意系统（实时查看数据使用，禁止后续使用）
算法偏见损失函数加入公平性惩罚项：L = 预测错例数 + λ × |组 1 误差 − 组 2 误差|
责任归属强制责任保险（AI 公司 + 医院缴费，医生未复核免赔 50%）
透明度分层告知模型（低危概括、中危具体、高危书面确认）
医生异化人机协同分级制（高置信快速复核、中置信详细复核、低置信独立诊断）
基准风险 0.20，SHAP 值：术前感染 +0.35、年龄 55 岁 +0.12、术后护理达标 −0.18、手术时长 90 分钟 +0.05。
最终风险 = 0.20+0.35+0.12−0.18+0.05 = 0.54；影响最大的特征是术前感染，方向为正向。

第 01 题 · 单选题基础高频

DIKW 体系中，「腋下体温正常范围 36~37℃」属于

第 04 题 · 单选题技术高频

Z-score 规范化的主要优点是

A. 将数据映射到 [0,1]
B. 对离群值不敏感，适用于大多数分布
C. 只能处理二值数据
D. 不需要计算均值

答案：B

第 13 题 · 名词解释技术高频

过拟合

答案：模型在训练集上表现很好，但在新数据（测试集）上表现明显变差的现象。

解析：过拟合的本质是模型学到了训练数据中的噪声而非规律。常见对策：增加样本量、正则化、Dropout、早停、交叉验证。与之相对的是欠拟合（模型过于简单）。

简化版：训练集表现好但测试集差，模型学到了噪声而非规律。

来源：第 3 章「机器学习原理」；《医学大数据导论》。

第 14 题 · 名词解释技术高频

卷积神经网络（CNN）

答案：以卷积层、池化层交替堆叠为特征、能自动提取图像局部特征的深度神经网络。

第 16 题 · 简答题技术高频

简述数据分析的六个基本步骤

答案：

  1. 明确目标：确定要解决的临床或业务问题
  2. 数据收集：确定来源、范围与合规要求
  3. 数据预处理：清洗重复/缺失/异常，规范化与降维
  4. 分析建模：选择合适算法训练与验证
  5. 数据可视化：以图形呈现关键发现
  6. 报告撰写：形成结论与建议，支撑决策

解析：六步是固定框架：目标→收集→预处理→建模→可视化→报告。其中预处理最耗时（约 70%），报告环节最易被忽视——没有清晰的结论表达，前面的工作无法转化为决策。

来源：第 2 章「数据分析流程」；《医学大数据导论》。

第 17 题 · 简答题应用高频

简述医学 AI 产品从需求到落地的关键阶段

答案：

  1. 需求分析：明确临床痛点与成功标准（如敏感性 ≥95%）
  2. 数据治理：合规采集、标注质控（Kappa 值）、脱敏与隐私保护
  3. 模型开发：算法选择 + 可解释性设计
  4. 临床验证：回顾性（AUC/敏感度）与前瞻性（临床终点）
  5. 注册审批：NMPA 或 FDA 审评
  6. 上市后监测：真实世界效果与不良事件追踪

解析：七阶段的核心是「数据治理」与「临床验证」两关：前者决定模型上限，后者决定能否进临床。注册审批是合规门槛，上市后监测是安全底线。

来源：第 6 章「医学可用人工智能」；《医疗器械软件审查指导原则》。

第 18 题 · 论述题应用高频

论述医学人工智能面临的主要挑战及应对思路

答案：

  1. 数据层：标注成本高、隐私敏感、多中心数据异质性强 → 联邦学习、迁移学习、半监督标注
  2. 技术层：模型可解释性差、泛化能力不足 → 可解释 AI、外部验证、多中心队列
  3. 临床层：与工作流融合难、医生接受度低 → 人机协同设计、临床决策支持嵌入
  4. 伦理层：算法偏见、责任归属不清 → 伦理审查、算法审计、明确责任边界
  5. 监管层：审批标准与快速迭代的矛盾 → 沙盒监管、上市后真实世界监测

解析：挑战可分「数据—技术—临床—伦理」四层。答题时每层都要落到具体问题与对策，避免空谈。核心矛盾是：AI 需要海量高质量数据，而医学数据恰恰稀缺、敏感、标注昂贵。

案例：例如某肺结节检测 AI 在三甲医院数据上敏感性达 95%，但推广到县域医院后性能明显下降——原因是设备参数与人群特征不同。解决思路是收集目标医院数据做本地化微调，并做前瞻性验证，而非直接套用原模型。

来源：第 6 章「医学可用人工智能：产品、可解释性与伦理」；《医学大数据导论》。
