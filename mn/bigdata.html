智能与人工智能

基本概念名词解释绪论

一、智能的本质

智能 = 知识 + 智力。其中知识是人类智能行为的基础，智力是能够感知、理解、获取、记忆、应用知识的能力。

智能的五大特征：感知能力、记忆能力、思维能力、行为能力、学习能力。

单选题常把「知识 + 能力」和「知识 + 智力」混在一起。正确表述是 知识和智力的总和。

二、图灵与人工智能的提出

  • 阿兰·图灵被称为「计算机之父」与「人工智能之父」。
  • 首次提出「图灵机」的设想，用于辅助数学问题与决策研究。
  • 研制早期电子计算机「炸弹」，用于破解德军的 Enigma 情报。
  • 发表划时代著作《计算机械和智能》，首次提出机械智能的概念，并提出「图灵测试」。
  • 1966 年 ACM 设立图灵奖，表彰计算机研究领域的杰出贡献者。

三、人工智能的定义

人工智能是关于知识的科学：研究使用计算机模拟人类智能行为（学习、推理、思考、规划等），继而用于研究知识的发现、表征与应用。

四、人机智能的关系

人工智能是人类智能的投影与拓展延伸：通过计算机模型模拟人类智能处理实际问题，并通过反馈持续优化效能。注意方向——是「人工智能对人类智能的模仿与拓展」，而不是反过来。

「智能与人工智能的关联」多选题中，正确项是「人工智能是对人类智能的模仿」「人工智能是对人类智能的拓展」；凡是把人类智能说成「对人工智能的拓展/延伸」的都是错的。

三、大数据与医学大数据

大数据的三大论断：大数据是人们获得新知、创造价值的源泉；大数据是改变市场、组织机构以及政府与公民关系的方法；大数据的核心是预测。2011 年全球生产数据 1.82 ZB。

大数据（国标 GB/T 35295-2017）：具有体量大、来源多样、生成极快且多变等特征，难以用传统数据体系有效处理的海量数据集。

大数据国家标准是 GB/T 35295-2017，选择题常直接考这个编号。

四、数据存储单位

换算链：[[bit → Byte → KB → MB → GB → TB → PB → EB → ZB → YB → BB → NB → DB]]，其中 1 Byte = 8 bit，其后各单位均为 1024 倍递进。

影像数据量计算：总 bit 数 ÷ 8 = 总字节数，再 ÷1024 得 KB。例如 20 层 × 512×512 像素 × 12 bit = 7 864 320 B ÷ 1024 = 7680 KB。

医学信息标准

信息标准必考场景对应

一、为什么需要标准

标准需求：解决名词术语与编码不统一、传输格式不规范、系统异构兼容等问题，打破「信息孤岛」。

标准化的三项要求：Consistency 一致性、Interoperability 互操作性、Repeatability 可重复性。

标准定义：卫生业务中信息采集、传输、交换、利用的统一规则、概念、术语、代码和技术。

二、四大常用标准（场景对应表）

三、按功能分类

核心类别包括：生物医学术语（ICD、SNOMED-CT）、分类代码标准（DRG）、信息交换标准（HL7、DICOM）、标识标准、文档和消息规范等。

DRG（疾病诊断相关分组）属于分类代码标准，是医保支付方式改革的核心工具。

数据分析流程与数据预处理

数据处理PCA流程

一、数据分析基本流程（六步）

明确目标 → 数据收集 → 数据预处理 → 分析建模 → 数据可视化 → 报告撰写。

二、为什么要预处理

现实数据是「脏数据」，普遍存在重复、不完整、不准确、不一致、高维度五类问题，直接建模会导致结果失真。

三、关键策略

策略做法说明
数据离散化二值数据（男→1、女→0）；多值数据用数值法或 One-hot 编码把连续量转为类别量
数据规范化最小-最大标准化：映射到指定区间；Z-score 规范化Z-score 对离群点不敏感
数据降维主成分分析 PCA把多变量重组为正交综合变量，保留核心信息
经典例题：把 31 个地区、10 项医疗指标降维至 3 个主成分，累计贡献率 93.05%。这三个数字常出现在填空或选择中。
最小-最大标准化对离群点敏感，Z-score 规范化对离群点不敏感。题目问「哪种方法对离群点不敏感」选 Z-score。

机器学习与深度学习

机器学习原理与模型分类

机器学习模型分类易混辨析

一、起源与定义

机器学习由 Arthur Samuel 于 1959 年提出，核心是通过训练数据挖掘规律，用于测试数据预测，再通过评估结果优化模型效能，即「基于过去，预测未来」。代表性早期成果是 Samuel 的跳棋程序。

人工智能 ⊇ 机器学习 ⊇ 深度学习。人工智能是上位概念，机器学习是人工智能的核心实现方法。题目问「机器学习与人工智能的关系」→ 选「后者包含前者」。

二、算法框架全流程

  • 问题分析与数据收集：区分有标记数据（监督学习）与无标记数据（无监督学习）。
  • 数据预处理与特征工程：预处理含图像增强、标准化、缺失值处理；深度学习可弱化传统人工特征工程的作用。
  • 特征选择与降维：均为防止过拟合、降低复杂度。
  • 模型分类：监督学习、无监督学习、半监督学习。
  • 模型评估：依赖数据集划分——训练集相当于平时作业、验证集相当于模考、测试集相当于高考。
特征选择 = 从原始特征群组中选取特征子集（不改变特征本身）；特征降维 = 把特征映射到新的低维空间（会产生新的综合特征）。两者原理不同，这是经典选择题。

三、模型分类及核心场景

类型数据核心任务医学场景
监督学习带标签数据分类（标记离散）、回归（标记连续）病变良恶判断（分类）、血糖水平预测（回归）
无监督学习无标签数据聚类（按相似性分组）乳腺癌分子分型
半监督学习少量有标签 + 大量无标签提升模型性能标注成本高的影像数据
「半监督学习仅使用无标记数据训练，监督学习仅使用有标记数据训练」——错误。半监督学习是两者结合。另外「聚类、降维属于监督学习任务」也是错的，它们属于无监督学习。

四、模型评估

分类模型评估「分类正误」，回归模型评估「预测值与真实值的差异」。

神经网络与卷积计算

深度学习CNN计算题

一、深度学习与传统机器学习的区别

对比维度深度学习传统机器学习
特征提取自动提取高层次特征，无需人工干预依赖人工设计特征
处理流程端到端连续流程（原始数据→输出）多阶段拆分（特征提取→模型训练→预测）

深度学习由 Geoffrey Hinton 等人于 2006 年提出，是机器学习的子集。

二、神经网络基础

人工神经元接收输入（x₁~xₙ）、权重（w₁~wₙ）和偏置（b），通过加权求和 + 激活函数输出结果。

多层感知器（MLP）：输入层（接收原始数据）→ 隐藏层（逐层提取特征）→ 输出层（输出预测结果）。

代表性模型：CNN（卷积神经网络）、RNN/LSTM（时序数据处理）、GAN（生成对抗网络）、Transformer（注意力机制）。

三、卷积网络关键环节

层作用关键点
卷积层核心特征提取卷积核 Kernel、滑动窗、步长 Stride、填充 Padding；本质是对数据加权（点乘）提取边缘与纹理
池化层降维与特征汇聚最大池化取局部最大值保留显著特征；平均池化取局部平均值平滑特征；不改变特征图深度
全连接层分类/预测位于网络末端，通过 Softmax 转化为概率

四、输出尺寸计算公式（必背）

W2 = (W1 + 2P - Wk) / S + 1
H2 = (H1 + 2P - Wk) / S + 1
输出深度 = 卷积核数量

W1/H1：输入宽/高   Wk：卷积核尺寸   P：Padding   S：Stride
① 输入 10×10，卷积核 3×3，P=1，S=1 → (10+2−3)/1+1 = 10×10（尺寸不变）。
② AlexNet CONV1：输入 227×227×3，96 个 11×11 卷积核，S=4，P=0 → (227+0−11)/4+1 = 55×55，输出深度 96。

五、典型卷积网络

模型特点
LeNet-5早期经典，用于手写数字识别，含卷积层、下采样层、全连接层
AlexNet2012 年 ILSVRC 夺冠，引入 ReLU 与双 GPU 并行
ResNet引入残差块与 BatchNorm，解决深层网络梯度消失，可传递底层信息到高层
ViT用 Transformer 处理图像，大规模数据集下效果优于 CNN
池化层不仅能降维，还能通过局部特征汇聚实现去噪（最大池化保留显著特征、抑制噪声）。说它「无法减少噪声影响」是错的。

自然语言处理的技术流程

NLP技术流程必考

一、NLP 的定义与两大方向

自然语言处理通过计算机与 AI 技术对人类自然语言进行有意义的分析与处理，核心是 NLU（自然语言理解） 与 NLG（自然语言生成）。

方向含义例子
NLU 自然语言理解使机器理解文本内涵、消解歧义「他的父亲做了手术」中判断父亲是患者而非执行者
NLG 自然语言生成把非语言数据转化为人类语言医学影像报告自动生成

NLP 模仿人类语言学习路径（字→词→语句→篇章→语法规则），通过「模仿—表征—拓展—延伸」实现语言处理。

二、核心技术流程（底层到高层）

环节任务示例
分词把文本拆为最小语义单位「脑实质未见异常强化信号」→ 脑实质 | 未见 | 异常 | 强化 | 信号
词性标注标注词语语法类别名词 n、动词 v、形容词 a；需解决兼类词问题

影像组学与影像智能分析

影像组学特征提取高频考点

一、影像组学概述

影像组学由 Philip Lambin 与 Robert J. Gillies 合作提出，核心是把常规医学影像转化为高通量定量特征空间，通过自动提取特征构建预测模型，实现疾病个体化诊疗（诊断、疗效评估、预后预测）。核心理念是「Meten is weten（测量即知）」。

关键文献：2012 年《Eur J Cancer》、2014 年《Nat Comm》、2017 年《Nat Rev Clin Oncol》等奠定领域基础。

「影像组学的最终目标是疾病诊断」——不全面。影像组学目标是诊断、疗效评估、预后预测三方面，只提诊断是错的。

二、核心流程（四步闭环）

  • 感兴趣区 VOI 分割：人工或自动勾勒目标区域（如肿瘤）。
  • 特征提取：提取形态、灰度直方分布（一阶统计）、纹理（二阶/高阶统计）三类特征。
  • 特征筛选：剔除冗余特征（如 RFE-SVM 方法），提升模型效率。
  • 建模评估：采用回归（LASSO、线性回归）、分类（SVM、决策树）算法，通过 ROC/AUC 验证性能。

三、三类特征对比（高频）

特征类别具体指标关键判断
形态特征长径、短径、面积、体积、形状指数与图像灰度无关，只依赖目标区域的形状和大小

四、Needleman-Wunsch 算法（全局比对）

该算法计算两个序列的最长公共子序列（LCS），量化相似性。

若 ai = bj：LCS(i, j) = LCS(i-1, j-1) + 1
若 ai ≠ bj：LCS(i, j) = Max( LCS(i-1, j-1), LCS(i, j-1), LCS(i-1, j) )
  • 算法步骤：初始化 LCS 矩阵 → 填充矩阵计算得分 → 回溯矩阵获取匹配字符串。
  • 实例：A = GGATCGA，B = GAATTCAGTTA，计算得 LCS(A,B) = 6。
  • 计算题实例：A = GATC，B = GACT，LCS = 3，匹配字符串如 A: GAT_，B: GA_CT。

二、理论框架与原理

核心框架：输入（Token 化 → 词嵌入）→ 计算（Transformer 架构）→ 输出（自回归生成）。

Q = [2,1]（疼痛），K1 = [1,2]（胆囊炎），K2 = [0,1]（肺炎），d = 2（√d ≈ 1.414）。
原始分数：Q·K1 = 4，Q·K2 = 1；缩放分数：4÷1.414 ≈ 2.8，1÷1.414 ≈ 0.7；模型更关注 K1（胆囊炎）。

三、医学应用

核心场景：病历自动生成（结构化率 98%）、影像诊断、手术方案规划、USMLE 考试（Med-PaLM 2 通过率 85%）、多模态会诊。GPT-4 在复杂问答中接近人类专家，而轻量化微调模型在判别型任务（实体抽取）中占优。

四、具身智能

具身智能是通过主动感知与认知物理世界、做出符合人类预期行为响应的 AI 系统，强调自主交互与学习，属于行为主义学派。核心要素：感知（CNN、ViT）→ 决策（LLM、WMs）→ 行动（机器人控制）。

阶段时间特征
早期萌芽1950s—1990s符号主义主导，「逻辑规则 + 机器人」尝试（如 WABOT-1）

「道」（算法）：CV/NLP/RL → LLMs/MLLMs → 世界模型 WMs。「器」（硬件）：自动化 → 大模型 + 机器人（「20 岁大脑 + 1 岁身体」）→ 自主化。挑战包括仿真到现实的鸿沟、数据稀疏、泛化性、可解释与安全性。

二、可解释性理论（难点）

维度内在可解释 Interpretable事后可解释 Explainable
本质模型本身为白盒黑箱 + 事后解释工具
方法线性回归、决策树、CAMSHAP、LIME、Grad-CAM
适用场景急诊、手术、危急值筛查、辅助诊断
「深度学习 + Grad-CAM」「随机森林 + LIME」「XGBoost + SHAP」都属于事后可解释，只有决策树、Lasso 回归这类本身结构透明的模型才是内在可解释。

SHAP 计算特征的边际贡献加权平均；LIME 做局部线性近似；Grad-CAM 用于图像类 AI 可视化。局限是解释精度与模型性能不可兼得，并存在「解释悖论」（无限追问）。

急诊心梗风险分层需 30 秒出结果且医生能直接理解逻辑 → 选 Lasso 回归（内在可解释、计算快），而不是深度学习集成模型。

三、医学 AI 的伦理问题（四大原则）

具体伦理问题：数据伦理（知情同意伪命题）、算法偏见、责任归属、透明度缺失、医生角色异化。核心立场是：AI 是「医生助手」而非「替代者」，坚守「以患者为中心」。

四、伦理解决策略

问题策略

简述过拟合的常见防治方法。

参考答案：

  1. 增加训练数据量：最根本的手段，可降低模型对噪声的敏感
  2. 简化模型：减少参数数量、降低网络层数或树深度
  3. 正则化：L1/L2 正则化限制参数大小
  4. 交叉验证：用 k 折交叉验证评估泛化能力

  7. 数据增强：通过变换扩充训练样本

解析：过拟合的本质是「模型复杂度超过了数据所能支撑的信息量」，因此要么加数据、要么降复杂度。

简述影像组学研究的标准流程。

参考答案：

  1. 图像采集：统一扫描参数与重建算法，保证数据一致性
  2. 图像分割：勾画感兴趣区（ROI），可手工、半自动或自动
  3. 特征提取：提取形状、一阶统计、纹理与小波等定量特征
  4. 特征选择：去除冗余与不稳定特征，常用 LASSO、随机森林
  5. 模型构建：用机器学习或深度学习建立诊断或预后模型
  6. 验证：内部验证与外部验证，报告 AUC、校准曲线与决策曲线
  7. 报告规范：遵循 IBSI 特征定义与 Radiomics Quality Score 要求

解析：影像组学最大的挑战是「可重复性」——扫描参数、分割方式与特征定义的差异都会导致结果无法复现。
