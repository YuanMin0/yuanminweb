细胞和组织的适应与损伤

适应：萎缩、肥大、增生、化生

掌握高频概念
类型定义举例
萎缩已发育正常的细胞、组织或器官体积缩小脑萎缩、肾萎缩、废用性萎缩
肥大细胞体积增大致器官体积增大心肌肥大（高血压）、骨骼肌肥大
增生细胞数目增多致组织器官增大前列腺增生、乳腺增生
化生一种分化成熟的组织被另一种分化成熟组织取代支气管假复层纤毛柱状上皮 → 鳞状上皮（吸烟）、宫颈柱状上皮 → 鳞状上皮
化生常发生在「不耐刺激」的上皮被「耐刺激」的上皮替代，是一种适应性改变，但==化生的上皮可成为癌变的基础（如鳞癌）==。

变性：可逆性损伤

掌握形态可逆
类型本质常见部位
细胞水肿（水样变性）Na⁺-K⁺ 泵失灵、细胞内水钠潴留肝、心、肾（缺氧、感染时最早出现）
脂肪变细胞内甘油三酯蓄积肝（脂肪肝，「槟榔肝」切面油腻）
玻璃样变细胞内或间质出现均质红染蛋白性物质肾小球入球小动脉（高血压）、浆细胞 Russell 小体、瘢痕组织
淀粉样变淀粉样蛋白沉积于细胞间质脾、肾、心（HE 染呈淡红色均质）
黏液样变间质内黏多糖蓄积动脉粥样硬化斑块、甲状腺功能低下
变性是可逆性损伤——去除病因后可恢复；细胞死亡（坏死、凋亡）不可逆。==判断分水岭是细胞膜与细胞核的改变==。

坏死与凋亡

掌握高频鉴别
坏死类型特点好发
凝固性坏死蛋白质变性凝固，结构轮廓保留，呈灰白/灰黄心、肾、脾（贫血性梗死）
液化性坏死组织迅速溶解液化脑（脑软化）、脓肿
纤维素样坏死胶原纤维断裂、呈细丝状红染风湿病、结节性多动脉炎、急进性高血压
干酪样坏死彻底凝固性坏死，镜下无结构红染颗粒，肉眼豆腐渣样结核病

坏疽（坏死 + 腐败菌感染）

类型部位特点
干性坏疽四肢末端（动脉阻塞、静脉通畅）干燥皱缩、黑褐色、界限清楚
湿性坏疽肠、子宫、肺（动静脉均阻塞）湿润肿胀、恶臭、界限不清，易致中毒
气性坏疽深部肌肉创伤（产气荚膜梭菌）捻发音、进展迅速，最危险

凋亡：单个细胞主动的程序性死亡，细胞膜完整、形成凋亡小体、无炎症反应；与坏死（成片、膜破裂、引发炎症）相反。

局部血液循环障碍

血栓形成

掌握高频条件

血栓形成是活体心血管内血液凝固或血液中某些成分析出凝集形成固体质块的过程。

三大条件

类型形成条件常见部位
白色血栓血流较快心瓣膜、动脉（血小板小梁 + 少量纤维蛋白）
混合血栓血流变慢、涡流静脉（血栓头部白色、体部混合）
红色血栓血流停止静脉（纤维蛋白网罗大量红细胞）
透明血栓（微血栓）微循环内DIC（纤维蛋白性血栓）
溶解吸收、机化再通、钙化；==血栓脱落则成为栓子==。

栓塞与梗死

掌握高频鉴别

栓塞：循环血液中出现不溶于血液的异常物质（栓子）随血流运行阻塞血管。最常见的是血栓栓塞。

栓子来源运行途径栓塞部位
左心/体循环动脉体循环动脉脑、脾、肾、下肢
右心/体静脉肺动脉肺栓塞（最常见、可猝死）
门静脉系统门静脉肝内门静脉分支
梗死类型形成条件好发器官肉眼
贫血性（白色）梗死动脉阻塞、组织致密、侧支少心、肾、脾灰白色、境界清楚、三角形
出血性（红色）梗死动脉阻塞 + 静脉淤血 / 双重血供、组织疏松肺、肠暗红色、出血明显
肺、肠因为「双重血供 + 组织疏松」，梗死后血液从侧支涌入坏死区，形成==出血性梗死==；而心、肾、脾组织致密，形成==贫血性梗死==。

炎症

炎症的基本病理变化

掌握高频机制

炎症的基本病理变化是变质、渗出、增生，其中渗出是炎症最具特征性的改变。

炎症类型主要细胞常见疾病
浆液性炎—（以浆液渗出为主）感冒初期、烫伤水疱
纤维素性炎—（纤维蛋白渗出）大叶性肺炎、白喉、风湿性心包炎（绒毛心）
化脓性炎中性粒细胞脓肿、蜂窝织炎、阑尾炎
出血性炎红细胞大量渗出流行性出血热、炭疽
渗出液：蛋白高、细胞多、比重＞1.018、易凝固（炎症）；漏出液：蛋白低、细胞少、比重＜1.018（心衰、低蛋白）。

慢性炎症与肉芽肿性炎

掌握鉴别高频

肉芽肿性炎是巨噬细胞及其衍生细胞（上皮样细胞、多核巨细胞）局限性增生形成的结节状病灶。

类型代表疾病特征
感染性肉芽肿结核病结核结节：中央干酪样坏死 + 上皮样细胞 + 朗汉斯巨细胞 + 外周淋巴细胞
异物性肉芽肿缝线、滑石粉异物周围巨噬细胞与多核异物巨细胞，无干酪样坏死
风湿小结风湿病Aschoff 细胞、中心纤维素样坏死
朗汉斯巨细胞核呈马蹄形排列于周边（结核）；异物巨细胞核杂乱分布于胞质中（异物）。==看核的排列方式就能区分==。

肿瘤

肿瘤的异型性与生长方式

掌握高频鉴别

异型性是肿瘤组织在细胞形态和组织结构上与其起源正常组织的差异，是判断良恶性的关键依据。

良性肿瘤恶性肿瘤
异型性小大（核大深染、核仁明显、核分裂象多、可见病理性核分裂）
生长方式膨胀性，常有包膜浸润性，无包膜
生长速度慢快，可伴坏死出血
复发转移不转移、少复发易转移、常复发
良性看「像不像」正常组织（异型性小），恶性看「跑到哪去」（浸润 + 转移）。==病理性核分裂象是恶性的重要标志==。

肿瘤的扩散与癌前病变

掌握高频扩散
转移途径常见肿瘤
淋巴道转移癌最常见（如乳腺癌 → 腋窝淋巴结）
血道转移肉瘤多见；癌晚期也可，肝、肺最常见
种植性转移胃癌 → 卵巢（Krukenberg 瘤）、腹膜种植

癌与肉瘤的区别

癌肉瘤
组织来源上皮组织间叶组织
发病率多见少见
转移淋巴道为主血道为主
镜下癌巢形成，与间质分界清弥漫分布，与间质分界不清

癌前病变：本身不是癌，但具有癌变潜能的病变，如黏膜白斑、慢性萎缩性胃炎伴肠上皮化生、结肠腺瘤性息肉、乳腺导管上皮不典型增生。原位癌：上皮全层异型增生但未突破基底膜。

心血管系统疾病

动脉粥样硬化与高血压

掌握高频病理

动脉粥样硬化（AS） 的基本病变是脂质沉积于动脉内膜，形成粥样斑块。演进：脂纹 → 纤维斑块 → 粥样斑块 → 复合病变（溃疡、钙化、血栓、动脉瘤）。

高血压的基本病理改变：

血管/器官改变
细动脉玻璃样变（透明变性）——血浆蛋白沉积，管壁增厚、管腔狭窄
小动脉增生性小动脉硬化（洋葱皮样），见于急进型高血压
心脏左心室向心性肥大，晚期离心性扩张
肾脏原发性颗粒性固缩肾（双侧对称、细颗粒）
脑脑软化、脑出血（基底节、内囊最常见）
高血压肾：双侧对称细颗粒；慢性肾盂肾炎肾：双侧不对称、凹陷性瘢痕 + 肾盂变形（见「器官系统基础IV」）。

心肌梗死

掌握高频并发症

心肌梗死多因冠状动脉粥样硬化合并血栓形成导致管腔闭塞，属贫血性梗死。好发部位依次为左心室前壁、心尖部、室间隔前 2/3（左前降支供血区）。

心律失常（最常见）、心力衰竭、心源性休克、心脏破裂（1～2 周）、室壁瘤、附壁血栓。

呼吸系统疾病

肺炎的类型与病理

掌握高频鉴别
大叶性肺炎小叶性肺炎（支气管肺炎）
病原肺炎链球菌多种细菌混合（金葡、肺炎克雷伯等）
炎症类型纤维素性炎化脓性炎
范围肺段或大叶以细支气管为中心的小叶
好发人群青壮年小儿、老年、体弱者
并发症肺肉质变、肺脓肿、脓胸心衰、呼衰、脓肿

大叶性肺炎四期：充血水肿期 → 红色肝样变期 → 灰色肝样变期 → 溶解消散期。灰色肝样变期肺泡腔内充满纤维蛋白与中性粒细胞，肉眼呈灰白色、质实如肝。

慢阻肺：慢性支气管炎（黏液腺增生、杯状细胞增多）与肺气肿（肺泡扩张、间隔断裂，桶状胸）。

鳞状细胞癌与吸烟最相关、中央型多见；腺癌女性多见、周围型；小细胞癌恶性度最高、早期转移。

消化系统疾病

消化性溃疡与肝硬化

掌握高频病理

一、消化性溃疡

好发于胃小弯近幽门侧与十二指肠球部。溃疡呈圆形或椭圆形，直径多＜2 cm，边缘整齐、底部平坦、周围黏膜放射状皱襞。

镜下底部四层结构：渗出层（炎性渗出物）→ 坏死层 → 肉芽组织层 → 瘢痕层。

并发症：出血、穿孔、幽门梗阻、癌变（十二指肠溃疡几乎不癌变，胃溃疡癌变率＜1%）。

二、肝硬化

肝硬化是各种慢性肝病发展的晚期阶段，特征性病变是假小叶：肝细胞结节状再生 + 纤维结缔组织增生，分割包绕形成。

胃溃疡可癌变（＜1%），十二指肠溃疡几乎不癌变；假小叶是肝硬化的特征性病变，也是诊断依据。

第 06 题 · 名词解释细胞和组织的适应与损中频课件考点

化生

完整版：一种分化成熟的组织受刺激因素作用，转化为另一种相似性质的分化成熟组织的过程。常见的化生有上皮组织的鳞状上皮化生、柱状上皮化生，以及间叶组织的骨化生、软骨化生。化生是机体对刺激的一种适应性反应，但也可成为肿瘤发生的基础。

简化版：分化成熟组织受刺激转化为另一种相似性质的分化成熟组织；常见鳞状上皮化生、肠上皮化生、骨与软骨化生；属适应性反应，也可为肿瘤发生基础。

来源：《病理学》名解与大题（酱油坊整理），P1–P6

第 07 题 · 名词解释细胞和组织的适应与损中频课件考点

凝固性坏死

完整版：坏死细胞的蛋白质发生凝固，常保留组织结构的轮廓残影。多见于心、肝、肾等实质器官的缺血性坏死，肉眼呈灰白或灰黄色、质地坚实的凝固体，镜下细胞核消失但组织轮廓可辨。

简化版：坏死细胞蛋白质凝固，保留组织结构轮廓残影；多见于心肝肾缺血性坏死，肉眼灰白坚实，镜下核消失但轮廓可辨。

来源：《病理学》名解与大题（酱油坊整理），P1–P6

第 66 题 · 论述题肿瘤中频课件考点

论述良恶性肿瘤的鉴别要点与恶性肿瘤的扩散途径。

参考答案：

  1. 分化与异型性：良性分化好、异型性小；恶性分化差、异型性大，可见病理性核分裂
  2. 生长速度：良性缓慢，常呈膨胀性生长并有包膜；恶性较快，呈浸润性生长、多无包膜
  3. 复发与转移：良性极少复发与转移；恶性易复发并可发生转移
  4. 对机体影响：良性以压迫阻塞为主；恶性可致坏死出血、恶病质与广泛转移
  5. 直接蔓延：肿瘤沿组织间隙连续浸润生长，累及邻近器官
  6. 淋巴道转移：癌多经淋巴道转移，首先至区域淋巴结
  7. 血道转移：肉瘤多经血道转移，常见于肺、肝、骨、脑
  8. 种植性转移：瘤细胞脱落后种植于体腔浆膜面，如胃癌种植至卵巢形成 Krukenberg 瘤

案例：例如，一名 58 岁男性因上腹隐痛、消瘦就诊，胃镜见胃窦部溃疡型肿物，活检示腺体结构紊乱、细胞异型性明显、可见病理性核分裂，诊断为胃腺癌。术中见肿瘤已穿透浆膜并侵犯胰腺，腹腔内见多发结节，术后病理证实为腹腔种植转移。该例体现了恶性肿瘤的浸润性生长、直接蔓延与种植性转移三种扩散方式。

解析：良恶性鉴别的核心是「异型性、生长方式、复发转移」三条，其中转移是恶性肿瘤最可靠的证据。

来源：《病理学》名解与大题（酱油坊整理），P1–P6

第 98 题 · 简答题消化系统疾病中频课件考点

简述门脉性肝硬化晚期腹水形成的机制。

参考答案：

  1. 门静脉压力增高：腹腔内脏血管床静水压升高，组织液回吸收减少而漏入腹腔
  2. 低清蛋白血症：肝脏合成白蛋白减少，血浆胶体渗透压下降，液体外漏
  3. 淋巴液生成过多：肝淋巴液自肝包膜表面漏入腹腔，超过淋巴循环引流能力
  4. 水钠潴留：继发性醛固酮与抗利尿激素增多，肾钠水重吸收增加
  5. 有效循环血容量不足：肾血流量减少，进一步激活肾素-血管紧张素-醛固酮系统

解析：腹水的五个机制中，门静脉高压与低蛋白血症是主因，水钠潴留是继发结果，因此治疗需限钠利尿并补充白蛋白。

第 100 题 · 论述题消化系统疾病中频课件考点

论述肝硬化门脉高压的形成机制与主要临床表现。

参考答案：

  1. 肝内血管受压：假小叶形成与纤维组织增生压迫肝内门静脉分支
  2. 肝内血管改建：纤维组织增生使肝血窦减少、血管床面积缩小
  3. 门静脉血流阻力增加：肝内门静脉与肝静脉分支间形成异常吻合，血流阻力升高
  4. 门静脉压力升高后侧支循环开放：食管胃底静脉曲张、腹壁静脉曲张、痔静脉曲张
  5. 脾大与脾功能亢进：脾静脉回流受阻，脾脏淤血肿大，出现三系减少
  6. 腹水：门静脉高压 + 低蛋白血症 + 淋巴液生成过多 + 水钠潴留共同作用
  7. 最危险并发症：食管胃底静脉曲张破裂出血，可致失血性休克

案例：例如，一名 55 岁男性乙肝肝硬化患者，出现腹胀、牙龈出血，查体见腹壁静脉曲张呈「海蛇头」、脾大、移动性浊音阳性，胃镜示食管下段静脉重度曲张伴红色征。其门脉高压由假小叶压迫肝内门静脉分支、肝血窦减少共同导致，侧支循环开放形成了腹壁与食管静脉曲张，最终因进食粗糙食物诱发曲张静脉破裂大出血。

解析：门脉高压的病理基础是「假小叶 + 纤维化导致肝内血管阻力升高」，其临床表现可归纳为「脾大脾亢、侧支循环、腹水」三大类。

来源：《病理学》名解与大题（酱油坊整理），P1–P6
