绪论：医学统计学基本概念

研究单位、变量与资料类型

名词解释考点单选高频

一、研究单位、变量与变量值

研究单位（unit）亦称观察单位，指研究中的个体，是根据研究目的确定的。变量（variable）是在研究过程中可以被测量、并且其取值或类别会发生变化的特征或属性；变量值则是变量的观察结果。

「研究降压药的效果」中，变量是血压值，变量值是 135 mmHg；「研究人群性别构成」中，变量是性别，变量值是男、女。变量会变化，常量不会变化。

二、资料类型（三分法）

资料类型决定后续能用什么统计方法，是本课程最基础也最常考的判别点。

类型别名特点举例
计量资料定量资料、数值变量用仪器或定量方法准确获得，有数字大小和单位身高 1.65 m、体重 52 kg
计数资料定性资料、无序多分类变量按属性划分类别，清点各类别个数血型 O/A/B/AB、阳性或阴性
等级资料有序分类变量、半定量资料各类别间有程度上的差别，但不能准确度量疗效：痊愈、显效、有效、无效
计数资料的两分类数据称 binary/dichotomous data（阳性/阴性、存活/死亡）；等级资料的关键是类别之间有等级顺序，如病情 Ⅰ/Ⅱ/Ⅲ 级、满意度好/中/差。

三、资料类型的转换

由计量资料转为等级资料是可以的，但由等级资料转回计量资料不可以——转换是单向的。

同质与变异、总体与样本、参数与统计量

名词解释考点

一、同质与变异

同质（homogeneity）指研究总体中的个体具有相同性质。例如研究西安市 2020 年 7 岁男孩身高，要求「同西安市、同 7 岁、同男孩、同无影响身高的疾病」。变异（variation）指个体观察值之间的差异。

没有同质性，资料就没有可比性；没有变异性，统计学就没有存在意义。统计学研究的正是同质群体中的变异规律。

二、总体与样本

概念定义细分
总体根据研究目的确定的同质观察单位的全体或观测值有限总体：可获得抽样框架；无限总体：不能获得抽样框架
样本从总体中选取的一部分个体或观测值的集合随机样本：每个个体有已知且非零的被抽中概率；非随机样本：概率未知或为零
抽样的目的是用样本信息推断总体特征。随机化是保证样本代表性的关键手段。

三、参数与统计量

概念含义符号举例性质
参数表示总体特征的统计指标总体均数 μ、总体标准差 σ、总体率 π固定的常数，但通常未知
统计量表示样本特征的统计指标样本均数、样本标准差 S、样本率 p在参数附近波动的随机变量
总体均数 μ 是常数不是随机变量；样本统计量是随机变量。所以只能说「置信区间包含 μ 的概率是 95%」，不能说「μ 落在区间内的概率是 95%」。

误差、频率与概率

考点名词解释单选高频

一、真值与误差

真值是没有任何误差的测量结果，为恒定的常数，但通常得不到，统计上一般用相同条件下大量重复测量结果的均值估计。误差是测量结果与真值之差，即 测量结果 = 真值 + 误差。

误差类型产生原因特点处理方式
随机误差测量过程中无法预测、无规律的随机波动不可预测、期望值为零、不可避免增大样本量可减小其影响
系统误差仪器未校准、测量者感官障碍或操作习惯、疗效标准偏高偏低有方向性、系统性或周期性地偏离真值通过实验设计和技术措施消除或减少
非系统误差研究者偶然失误，如仪器失灵、抄错数字、写错单位偶然出现，又称过失误差通过认真检查核对予以消除
抽样误差指样本统计量与总体参数之差，是一种常见的随机误差，由样本的随机性造成，不可避免但可以度量和控制。

二、频率与概率

在相同条件下独立地重复 n 次试验，随机事件 A 出现 f 次，则 f/n 为事件 A 出现的频率。当 n 逐渐增大时，频率 f/n 接近一个常数 c，称为事件 A 发生的概率 P(A)。

频率是就样本而言的，概率是从总体意义上说的。频率 f/n 是概率 P(A) 的估计值，样本量 n 越大，估计越可靠。经典例证：Buffon 投掷 4040 次得频率 0.5069，K. Pearson 投掷 24000 次得 0.5005。

集中趋势与离散趋势的描述

集中趋势：算术均数、几何均数、中位数与百分位数

考点计算单选高频

一、三个平均数指标一览

指标符号适用条件意义
算术均数样本 X̄、总体 μ对称分布，特别是正态分布反映平均数量水平
几何均数G呈偏态但经对数变换后呈对称分布（对数正态）反映对数转换后的平均数量水平
中位数M任何分布，特别是偏态、一端或两端无确切值、分布不明位次居中的值

二、算术均数

简称均数（mean），可用于反映一组呈对称分布的变量值在数量上的平均水平。计算方法有两种：

组中值 = （组段下限 + 组段上限）/ 2。例如组段 3.07~3.27 的组中值为 3.17。用组中值代替原始数据会带来一定误差，故频数表法只是近似。

三、几何均数

用于反映一组经对数转换后呈对称分布的变量值在数量上的平均水平，适用条件为分布呈偏态但经对数变换后呈对称分布的资料，如免疫学中的滴度资料。

直接法：G = lg⁻¹( (ΣlgX) / n )
频数表法：G = lg⁻¹( (Σf·lgX) / Σf )
抗体滴度 10、20、40、40、160 呈等比数列，取对数后 1、1.30、1.60、1.60、2.20 呈对称分布。若直接用算术均数会因 160 这一个极端值被明显高估。

四、中位数与百分位数

中位数（M）是 n 个变量值从小到大排列后居于中间位置的变量值，n 为奇数时取中间一个，n 为偶数时取中间两个的平均值。百分位数 P_X 是一种位置指标，中位数即 P₅₀。

直接法：设 (n+1)×X% = j + g（j 为整数部分，g 为小数部分）
g = 0 时：P_X = X_j
g ≠ 0 时：P_X = X_j + g·(X_(j+1) − X_j)
频数表法：P_X = L + (i / f_X)·(n·X% − Σf_L)
119 名细菌性痢疾治愈者住院天数：(119+1)×5% = 6，故 P₅ = 3 天，意义是有 5% 的治愈者住院天数少于 3 天；(119+1)×99% = 118.8，j = 118、g = 0.8，得 P₉₉ = 41.6 天。
百分位数的主要用途是确定医学参考值范围，此外也用于确定偏态分布资料的离散程度（四分位数间距）。

离散趋势：极差、四分位数间距、方差标准差与变异系数

考点计算单选高频

一、四个变异指标一览

指标适用条件特点
极差 R任何分布计算简便、适用范围广，但不灵敏、不稳定，不能反映组内其他数据的变异
四分位数间距 QR任何分布，特别是偏态分布包括居中 50% 的变量值，受样本波动影响较极差小
方差 σ²/S²正态或近似正态分布反映所有观测值与均数相距的平均距离，单位为原始观测值的平方
标准差 σ/S正态或近似正态分布单位与原始观测值相同，常与均数联合描述正态分布特征
变异系数 CV单位不同或均数相差悬殊的指标比较没有单位，CV 越大变异程度越大

二、关键公式

极差：R = X_max − X_min
四分位数间距：QR = P₇₅ − P₂₅
离均差平方和：SS = Σ(X − μ)²
总体方差：σ² = Σ(X − μ)² / N
样本方差：S² = Σ(X − X̄)² / (n − 1)
变异系数：CV = S / X̄ × 100%
四分位数间距 QR = P₇₅ − P₂₅。例：118 名链球菌咽喉炎患者潜伏期已知 P₂₅ = 39.2 天、P₇₅ = 67.7 天，则 QR = 67.7 − 39.2 = 28.5 天。

三、标准差与变异系数

正态分布资料常用「均数 ± 标准差」描述数据特征。例如某医院产科某月 100 个顺产新生儿出生身长可描述为 49.3 ± 3.77 cm。

某部队院校 20 岁女学员身高均数 166.06 cm、标准差 4.95 cm；体重均数 53.72 kg、标准差 4.96 kg。不能因为 4.96 > 4.95 就说体重变异大——两者单位不同，必须用变异系数比较。
身高 CV = 4.95 / 166.06 × 100% ≈ 2.98%
体重 CV = 4.96 / 53.72 × 100% ≈ 9.23%
结论：体重的变异程度比身高大。
甲、乙、丙三组 BMI 均数都是 16，但甲组标准差最小，说明甲组数据最集中，其均数的代表性最好。这说明仅有均数不足以描述一组数据的全貌，必须同时看离散程度。

应用平均数与变异指标的注意事项

考点简答

一、根据资料的分布特征正确选择平均数指标

指标意义适用范围
算术均数平均数量水平呈正态分布的资料
几何均数对数转换后的平均数量水平对数正态分布的资料
中位数位次居中的值常用于偏态分布、分布不明或末端无确切值的资料
选平均数指标的第一步是看分布：对称（正态）用算术均数，对数正态用几何均数，偏态或分布不明用中位数。

二、注意数据的同质性及其实际意义

例：某「留守村」现居住 60 人，平均年龄 36 岁。其中留守老人 25 人平均年龄 75 岁，留守儿童 35 人平均年龄 8 岁。这个「36 岁」是由两个完全不同质的群体混合计算出来的，没有实际意义。

把不同质的观察单位合并计算均数是常见错误。同质性是计算平均数的前提，异质资料合并后的平均数既不代表老人也不代表儿童。

三、变异指标的选择与注意事项

指标适用范围特点
极差偏态分布（任何分布）反映所有观测值的离散程度（实际仅取决于两端）
四分位数间距偏态分布反映中位数两侧 50% 观测值的离散程度
方差正态分布反映所有观测值与均数相距的平均距离，单位为原始观测值的平方
标准差正态分布单位与原始观测值相同
变异系数单位不同或均数相差悬殊的指标变异度比较无单位
分布形态决定指标选择：正态资料「均数 ± 标准差」成套使用；偏态资料「中位数 + 四分位数间距」成套使用。两者是配对出现的。

正态分布与医学参考值范围

正态分布及其特征

考点单选高频

一、概念与命名

正态分布的概念最早由法国数学家和天文学家 Moivre 提出，德国数学家 Gauss 率先将其应用于天文学研究，故正态分布又称 Gauss 分布。记作 X ~ N(μ, σ²)。

① 很多医学指标服从或近似服从正态分布，如同性别同年龄儿童身高、健康成人红细胞数、血红蛋白含量、脉搏数；② 有些非正态资料经变量变换后可转为正态；③ 随机误差服从正态分布；④ 正态分布是很多统计方法的理论基础。

三、标准正态分布与 u 变换

不同变量的正态分布曲线位置和形状不同（如身高与体重），同一变量在不同状态下也不同（如餐前与餐后血糖）。通过变量转换可将一般正态分布转化为通用的标准正态分布，记作 N(0, 1)。

u = (X − μ) / σ     称为标准正态离差（u 变换）
变换含义：将中心位置移至原点（μ = 0）
          将刻度单位定义为总体标准差（σ = 1）

医学参考值范围的制定

考点计算简答

一、基本概念

医学参考值指包括绝大多数正常人的人体形态、机能和代谢产物等各种生理及生化指标常数，也称正常值，通常是一个范围，称为医学参考值范围（medical reference range）。「绝大多数」一般取正常人的 90%、95%、99%；「正常人」指排除了影响所研究指标的疾病和有关因素的同质人群。

对于 1−α 医学参考值范围：①「落在参考值范围外的人一定不正常」——错；②「落在参考值范围内的人一定正常」——错；③「1−α 比例的正常人该指标分布在此范围内」——对。

二、单侧与双侧

类型含义举例
双侧无论过低或过高均属异常，需同时确定下限和上限血清总胆固醇、白细胞计数、红细胞计数
单侧上限过高异常，只需确定上限体内有毒物质、血清转氨酶、尿汞
单侧下限过低异常，只需确定下限肺活量

例 2-16：138 名正常成年女性红细胞均数 4.23、标准差 0.45（×10¹²/L），求 95% 参考值范围。下限 = 4.23 − 1.96×0.45 = 3.35，上限 = 4.23 + 1.96×0.45 = 5.11，即 3.35 ~ 5.11（×10¹²/L）。某患者红细胞 7.88×10¹²/L，超出上限，应引起注意。
例 2-17：282 名正常人尿汞值呈偏态分布、且为单侧上限问题，故用百分位数法计算 P₉₅，得 95% 医学参考值范围为 < 43.6 μg/L。判断顺序：先看分布（偏态→百分位数法），再看单双侧（尿汞过高异常→单侧上限）。

医学统计学

参数估计：总体均数与总体率的置信区间

均数的抽样误差与标准误

考点计算单选高频

一、抽样误差

由于样本随机性造成的样本统计量之间或样本统计量与总体参数之间的差异，称为抽样误差（sampling error）。

某市应征男青年身高 N(176, 4²)，每次随机抽取 n = 5 的样本重复 100 次：① 样本均数的分布服从正态分布；② 各样本均数间存在差异，未必等于总体均数，但总是围绕总体均数上下波动；③ 样本均数的变异范围较原观察值大大缩小，样本量越大变异越小。结论：抽样误差可以度量，且与样本量有关。

二、标准误的定义

标准误（standard error, SE）是反映统计量（如样本均数、样本率 p 等）之间变异的标准差，是表示样本统计量抽样误差大小的统计指标。均数标准误说明样本均数抽样误差的大小。

理论值：σ_X̄ = σ / √n
估计值：S_X̄ = S / √n     （总体标准差 σ 未知时用样本标准差 S 估计）
① 含义：标准差描述个体观察值之间的变异；标准误描述样本统计量之间的变异。② 与样本量的关系：标准差随 n 增大趋于稳定（σ 是常数）；标准误与 √n 成反比，n 越大标准误越小。③ 用途：标准差用于描述资料离散程度、计算参考值范围；标准误用于估计参数的可信区间、进行假设检验。
增大样本量 n 可以减小标准误（S_X̄ = S/√n）。减小 S 不能从根本上解决问题，因为 S 反映的是个体变异，由研究对象本身决定。

总体均数的估计与 t 分布

考点计算单选高频

一、点估计

点估计是使用样本统计量直接作为总体参数的估计值，如用 X̄ 估计相应的 μ，用 S 估计相应的 σ。该法表达简单，但未考虑抽样误差的影响，无法评价参数估计的准确程度。

二、区间估计与置信区间

区间估计是按预先给定的概率计算出一个区间，使它能够包含未知的总体参数。依据事先给定的概率 1−α（称为置信度，通常取 0.95 或 0.99），计算得到的区间称为置信区间（confidence interval, CI），包括下限 L 与上限 U。

三、t 分布

当 σ 未知、n 较小时，样本均数经变换后不服从标准正态分布，而服从 t 分布。t 分布由 William Gosset 于 1908 年发表（笔名 Student，故又称 Student t 分布）。

t 分布不是标准正态分布，它只在大样本或自由度很大时才近似于标准正态分布。t 分布是一簇曲线，其形状由自由度 v 决定。

四、总体均数 μ 的置信区间

σ 已知：      X̄ ± u_(α/2) · σ/√n
σ 未知，n 较小：X̄ ± t_(α/2, v) · S/√n     v = n − 1
σ 未知，n 足够大：X̄ ± u_(α/2) · S/√n
随机抽取正常男性 28 名，红细胞均值 5.04、标准差 0.44。n = 28 视为小样本，自由度 v = 27，查 t 界值表 t_(0.05/2, 27) ≈ 2.052。下限 = 5.04 − 2.052×0.44/√28 ≈ 4.87，上限 ≈ 5.21，即总体均数 95% 置信区间为 (4.87, 5.21)。

总体率的估计、两均数之差与两率之差的置信区间

考点计算

一、率的抽样误差与标准误

样本率 p 之间或样本率与总体率 π 的差异称为率的抽样误差，用率的标准误度量。样本率的标准差称为率的标准误（standard error of rate），可用来描述样本率抽样误差的大小。

理论值：σ_p = √( π(1 − π) / n )
估计值：S_p = √( p(1 − p) / n )

二、总体率的估计

根据二项分布原理，当 n 较大、p 和 1−p 均不太小（一般要求 np 和 n(1−p) 均大于 5）时，样本率 p 近似服从正态分布，可用正态近似法估计总体率的置信区间。

总体率 π 的 1−α 置信区间：p ± u_(α/2) · S_p
连花清瘟结合西医方案治疗普通型新冠肺炎患者 181 例，有效 150 例，有效率 82.9%。本例 np = 150、n(1−p) = 31 均大于 5，可用正态近似法。得总体有效率 95% 置信区间为 (77.4%, 88.4%)。

三、两均数之差与两率之差的置信区间

μ₁ − μ₂ 的 1−α 置信区间：
(X̄₁ − X̄₂) ± t_(α/2, v) · S_(X̄₁−X̄₂)
若两均数之差（或两率之差）的 95% 置信区间不包含 0，说明差别有统计学意义。例：两组降压药收缩压下降差值的 95% CI 为 (0.99, 11.49) mmHg，下限 > 0，未包括 0，说明试验药降压效果更好，最多多降 11.49 mmHg，最少多降 0.99 mmHg。
治疗牙本质过敏症：试验组 77 颗牙有效 61 颗（79.22%），对照组 69 颗有效 38 颗（55.07%）。两组总体有效率差值 95% 置信区间为 (8.96%, 39.34%)，下限 > 0，说明试验组总体有效率高于对照组，至少提高 8.96%，最多提高 39.34%。

四、置信区间的含义与评价

从总体中作随机抽样 100 次，每个样本可算得一个置信区间，共得 100 个置信区间，平均有 95 个置信区间包含 μ（估计正确），只有 5 个不包含 μ（估计错误）。实际工作中只计算一次置信区间，要么包含 μ 要么不包含，但可以说计算得到的置信区间包含 μ 的概率是 95%。

比较项95% 置信区间99% 置信区间
区间范围窄宽
估计错误的概率大（0.05）小（0.01）
准确度较低较高
精密度较高较低
准确度（accuracy）由置信度 1−α 反映，置信度越高估计结果越准确；精密度（precision）反映区间宽度，区间越窄精密度越好。在置信度确定的情况下，增加样本含量 n 可减小区间宽度。
① 总体均数 μ 是常数，由样本计算的置信区间是变化的，不能说 μ 以 1−α 的置信度落在置信区间内，而是置信区间以 1−α 的置信度包含 μ。② 事先预计置信区间以 95% 的可能性包含了 μ；事后该区间要么包含要么不包含。

假设检验与 t 检验

假设检验的基本原理与步骤

考点简答单选高频

一、差异的来源

例 9-1：某医院出生新生儿头围均数 34.50 cm、标准差 1.99 cm；调查该医院出生的矿区新生儿 55 人，头围均数 33.89 cm。均数差值 0.61 cm。这个差异可能来自：① 抽样误差（矿区环境不影响头围，差异纯属随机波动）；② 总体间固有差异（矿区环境确实影响头围）。

假设检验的目的就是判断样本所反映的差异究竟属于哪一种情况：若差异可以用抽样误差解释，则认为两总体相同；若不宜用抽样误差解释，则认为存在总体间固有差异。

二、基本思想

假设检验的方法由英国统计学家和遗传学家 R.A. Fisher（1890—1962，现代统计学奠基人之一）在「女士品茶」试验中设计，是统计学思想的重要来源。

三、假设检验的基本步骤

① 不拒绝 H₀ 不等于支持 H₀ 成立，仅表示现有样本信息不足以拒绝 H₀；② 对 H₀ 只能说拒绝或不拒绝，对 H₁ 只能说接受；③ 统计结论只说明有无统计学意义，不能说明专业上的差异大小；④ 结论应表述为「差别有/无统计学意义」，不应表述为「有/无显著性差别」。
例 9-1 得 P < 0.05，按 α = 0.05 水准拒绝 H₀、接受 H₁，差异有统计学意义（统计结论），可以认为矿区新生儿头围小于一般新生儿（专业结论）。

假设检验的两类错误与注意事项

考点单选高频简答

一、两类错误

真实情况结论：拒绝 H₀结论：不拒绝 H₀
H₀ 成立Ⅰ 类错误（概率 α）推断正确（概率 1−α）
H₀ 不成立（H₁ 成立）推断正确（概率 1−β）Ⅱ 类错误（概率 β）
减少 Ⅰ 类错误 α 会增加 Ⅱ 类错误 β；增大 Ⅰ 类错误 α 会减小 Ⅱ 类错误 β。想同时降低 α 与 β，唯一办法是增大样本量 n。

二、假设检验的注意事项

① α 是事先人为设定的，不是计算出来的；② P 是根据检验统计量查表或计算得到的，不是人为设定的；③ 假设检验推断的是两总体之间的差异，不是两样本之间的差异。

t 检验的三种类型与方差齐性检验

考点计算单选高频

一、单样本均数的 t 检验

用于推断样本所代表的未知总体均数 μ 与已知总体均数 μ₀ 有无差别。μ₀ 一般为理论值、标准值或经大量观察所得的稳定值。应用条件：样本所来自的总体为正态总体。

t = (X̄ − μ₀) / S_X̄ = (X̄ − μ₀) / (S / √n)      v = n − 1
某地 6 月龄正常婴儿血红蛋白平均水平 116.3 g/L。随机抽取 30 名母乳喂养婴儿，均数 108.1 g/L、标准差 11.8 g/L。H₀: μ = 116.3，H₁: μ ≠ 116.3，α = 0.05。计算得 t = 3.81，查表 t_(0.05/2, 29) = 2.045，|t| > 2.045，P < 0.05，拒绝 H₀，认为母乳喂养婴儿血红蛋白水平低于一般婴儿。
同一资料的 95% 置信区间为 (103.7, 112.5) g/L，不包含 116.3，与 t 检验结论相同。置信区间与假设检验对同一数据可得到一致结论。若事先有理由认为母乳喂养婴儿血红蛋白不会高于一般婴儿，可用单侧检验，t_(0.05, 29) = 1.699，|t| = 3.81 > 1.699，仍拒绝 H₀。

二、配对样本均数的 t 检验（配对 t 检验）

适用于配对设计的计量资料。配对设计主要有三种情形：① 两同质受试对象分别接受两种不同处理（如按同窝、同性别、体重相近配成对子）；② 同一受试对象分别接受两种不同处理（如同一份标本分成两部分）；③ 同一受试对象接受处理前后（自身前后比较，不能随机分配处理，应设立平行对照）。

d = X₁ − X₂（各对差值）
t = (d̄ − 0) / S_d̄ = d̄ / (S_d / √n)      v = 对子数 − 1
配对 t 检验的本质是样本均数 d̄ 与总体均数 0 的比较：先计算各对差值 d，再计算差值均数 d̄，检验 d̄ 是否来自总体均数为 0 的总体。若两种方法结果无差别，则差值的总体均数应为 0。应用条件：差值 d 服从正态分布。
A 法与 B 法测量 16 例近视患者中央角膜厚度，各对差值合计 335、平方和 7131。H₀: μ_d = 0，H₁: μ_d ≠ 0，α = 0.05。计算得 t = 30.02，查表 t_(0.05/2, 15) = 2.131，t > 2.131，P < 0.05，拒绝 H₀，认为两种方法测定的中央角膜厚度不同。

三、两独立样本均数的 t 检验（成组 t 检验）

适用于平行设计两样本均数的比较，样本含量较小。应用条件：两样本来自正态总体，且两总体方差相等（方差齐性）。

比较盐酸二甲双胍缓释片 Ⅱ 与二甲双胍片治疗 2 型糖尿病的效果，两组各 20 例。H₀: 两组 HbA1c 下降值的总体均数相等，H₁: 不相等，α = 0.05。计算得 t = 0.38，查表 t_(0.05/2, 38) = 2.024，t < 2.024，P > 0.05，不拒绝 H₀，尚不能认为两药降糖效果不同。两组均数之差的 95% 置信区间包括 0，与假设检验结论一致。

四、方差齐性检验与 t′ 检验

t 检验的条件是正态分布与方差齐性。正态性检验可用计算法（偏度系数、峰度系数）或图示法（P-P 图、Q-Q 图、直方图、箱图）；方差齐性检验用 F 检验，由两样本方差推断两总体方差是否相同。

方差齐性检验是双侧检验：当 H₀ 成立时，无论 F 值远远大于 1 还是远远小于 1，都应拒绝 H₀。例：F_(0.05/2, (10, 12)) = 3.37，若 F > 3.37 则 P < 0.05，认为两组总体方差不等。
